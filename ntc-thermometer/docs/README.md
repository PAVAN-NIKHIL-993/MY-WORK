## Provenance

This project was recovered from a saved browser session of the original design
conversation. The schematic, bill of materials and engineering analysis are
reproduced from that session. The supporting hardware artifacts (PCB layout, gerbers,
mechanical drawings, LCD datasheet) were **not** part of it and are therefore absent.

The saved page also contained personal account information; it was not committed.
See [`../README.md`](../README.md#provenance).
