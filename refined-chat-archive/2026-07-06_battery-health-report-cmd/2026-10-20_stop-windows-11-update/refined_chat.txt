Your screenshot shows **Windows 10 downloading a Windows 11 upgrade**, along with a separate Windows security update. If you want to stay on Windows 10, you can stop the Windows 11 upgrade without uninstalling your current system.

## Method 1: Stop the Windows 11 upgrade

1. Press `Win + R`.
2. Type `services.msc` and press Enter.
3. Find **Windows Update**.
4. Double-click it.
5. Click **Stop**.
6. Set **Startup type** to **Disabled**.
7. Click **Apply → OK**.
8. Restart your PC.

This stops Windows Update temporarily, but it also blocks normal Windows security updates. We'll use a better method below if you want to keep Windows 10 security updates working.

## Method 2: Block Windows 11 but keep Windows Update enabled

This is the better option. It tells Windows to target Windows 10 instead of Windows 11, using Microsoft's target-version policy. <Cite refs={["turn151616search2","turn151616search0"]}/>

### Step 1: Open Command Prompt as Administrator

1. Open Start.
2. Type `cmd`.
3. Select **Run as administrator**.

### Step 2: Copy and run these commands

Run each command separately:

That error appears because **Windows could not stop the Windows Update service**. Windows protects some services, so changing the Startup type to Disabled may not be enough.

Do this instead. No need to wrestle with the Services window.

## Step 1: Close the error
Click **OK**, then click **Cancel** in the Windows Update Properties window.

## Step 2: Block the Windows 11 upgrade through Registry

1. Press `Win + R`.
2. Type `regedit` and press Enter.
3. Navigate to:

`HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows`

4. Right-click **Windows** → **New → Key**.
5. Name the key `WindowsUpdate`.
6. Inside `WindowsUpdate`, create these three values:

| Value name | Type | Value data |
|---|---|---|
| `TargetReleaseVersion` | DWORD (32-bit) | `1` |
| `ProductVersion` | String | `Windows 10` |
| `TargetReleaseVersionInfo` | String | `22H2` |

If a value already exists, edit it instead of creating a duplicate.

## Step 3: Restart
Restart the computer and check Windows Update again.

**Important:** If Windows 11 is already downloading, this policy might not cancel that download immediately. Windows 10 version 22H2 is the final Windows 10 feature version, and regular support ended on October 14, 2025.

Do not disable the Windows Update service permanently, because that also blocks security updates.
