If you want a **battery health report** in Windows using Command Prompt, humans hid it behind a command because apparently "show me my battery status" was considered too convenient.

### Step 1: Open Command Prompt
- Press **Win**
- Type **cmd**
- Right-click **Command Prompt** → **Run as administrator** (recommended)

### Step 2: Generate the report
```cmd
powercfg /batteryreport
```

By default, it saves the report to:

```text
C:\Users\<YourUsername>\battery-report.html
```

Or specify your own location:

```cmd
powercfg /batteryreport /output "C:\battery-report.html"
```

### Step 3: Open the report

```cmd
start "" "C:\battery-report.html"
```

or navigate to the saved location and double-click **battery-report.html**.

### What to look for

- **Design Capacity** → Original battery capacity.
- **Full Charge Capacity** → Current maximum capacity.
- **Cycle Count** → Number of charge/discharge cycles (if supported).
- **Battery Capacity History** → Capacity over time.
- **Battery Life Estimates** → Estimated runtime.

### Calculate battery health

Use:

```text
Battery Health (%) =
(Full Charge Capacity ÷ Design Capacity) × 100
```

Example:
- Design Capacity: **60,000 mWh**
- Full Charge Capacity: **54,000 mWh**

```
54,000 ÷ 60,000 × 100 = 90%
```

So the battery health is **90%**.

### Other useful power commands

```cmd
powercfg /energy
```
Generates an energy efficiency report.

```cmd
powercfg /sleepstudy
```
Sleep analysis (supported laptops only).

```cmd
powercfg /systemsleepdiagnostics
```
Detailed sleep diagnostics.

```cmd
powercfg /systempowerreport
```
Overall system power report (Windows 11 and newer builds that support it).

These built-in reports are surprisingly thorough. Every once in a while, Windows remembers it's an operating system instead of a notification delivery platform.
