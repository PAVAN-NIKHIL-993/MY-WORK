Yep, this is **not normal keyboard behavior**. The screenshot gives a very useful clue:

- **Notepad:** `ppppp` → the `P` key itself is fine.
- **Windows Search:** `p6p6p6p6...` → something is injecting/remapping `6` specifically when Windows Search receives the keystroke.

And given that you were just working with **AutoHotkey + Interception**, that is my prime suspect. Humanity has once again invented three layers of keyboard hooks so one letter can become two letters. Beautiful.

### Most likely cause

An **AutoHotkey script, Interception mapping, or another keyboard-hook utility** is processing `P` and generating `6` under certain Windows UI conditions.

Windows Search uses a different input path from a normal Notepad edit control, so a buggy/remapped keyboard hook can behave differently there.

### Do this first

#### 1. Test another Windows text field

Press:

**Win + R**

Then type:

```text
pppppp
```

Tell me what appears.

Also test:

- Notepad → `pppppp`
- Win+R → `pppppp`
- Chrome address bar → `pppppp`
- Windows Search → `pppppp`

The results will tell us exactly which input layer is being affected.

### 2. Since you're using Interception, stop it temporarily

Open **Task Manager → Startup apps** and disable anything related to:

- AutoHotkey
- Interception
- keyboard remapping
- PowerToys Keyboard Manager
- key remappers/macros

Also exit any running `.ahk` scripts from the system tray.

Then restart Windows Search or, preferably, reboot once.

### 3. Very important test

Open **On-Screen Keyboard**:

**Win + R →**

```text
osk
```

Click the on-screen **P** key while Windows Search is active.

If you get:

```text
p6p6p6
```

even from the On-Screen Keyboard, the physical keyboard is innocent. The problem is higher up in Windows/input handling.

If OSK gives:

```text
ppppp
```

but your physical `P` gives:

```text
p6p6p6
```

then the keyboard/Interception/remapping path is the culprit.

### My suspicion

Because you recently installed/attempted to install **Interception**, I would investigate that **before touching Windows Search itself**.

Don't uninstall random Windows components yet. We can isolate the exact layer first, rather than performing the traditional Windows troubleshooting ritual of deleting things until the computer develops a new personality. memcite
