If you mean **recovering photos from a "Locked Gallery" or "Private Gallery" after the phone has been factory reset**, the answer depends on where those files were stored. Technology is wonderfully literal. It remembers bits, not regrets.

### If the phone was factory reset
A factory reset usually **erases the encryption keys** and the user data partition. On modern Android phones with file-based encryption, recovery is often **impossible** if:
- The photos were only stored in the phone's internal memory.
- There was no cloud backup.
- The phone has been used after the reset.

### Recovery tools (legitimate)
These can recover data only in certain situations:

- **DiskDigger** (Android, rooted devices work best)
- **EaseUS MobiSaver for Android**
- **Dr.Fone Data Recovery**
- **iMobie PhoneRescue**
- **Tenorshare UltData for Android**
- **FonePaw Android Data Recovery**
- **Android Debug Bridge (ADB)** if you have an existing backup.
- **Google Photos** (check Trash, Locked Folder backup status if supported)
- **Samsung Cloud** or **Secure Folder backup** (Samsung devices)
- **Xiaomi Cloud**
- **OneDrive**, **Dropbox**, or other cloud services

### If it was a Locked Folder in Google Photos
Recovery is only possible if:
- Locked Folder backup was enabled (available on supported devices).
- You restore from the same Google account.

Otherwise, a factory reset usually removes the encrypted contents.

### If it was Samsung Secure Folder
If you had:
- Samsung Cloud backup enabled for Secure Folder, restore from there.
- No backup, a factory reset normally makes the encrypted files unrecoverable.

### If it was an app like Gallery Vault, Calculator Vault, Keepsafe
Recovery depends on whether:
- The app created a cloud backup.
- You exported the files before formatting.

Without a backup, the encrypted vault data is usually lost after a factory reset.

### If you still want to try forensic recovery
Professional tools include:
- **Cellebrite UFED** (law enforcement/forensics)
- **Magnet AXIOM**
- **Oxygen Forensic Detective**
- **MSAB XRY**

These are expensive forensic suites and **still cannot recover data if Android encryption keys were destroyed by the factory reset**.

### Your chances
| Situation | Chance of recovery |
|-----------|--------------------|
| Internal storage + factory reset + Android 10+ | Very low to none |
| SD card (not formatted) | Good |
| Cloud backup exists | Excellent |
| Gallery vault with cloud sync | Good |
| Rooted phone, no factory reset | Moderate |
