Microsoft has made this unnecessarily annoying because apparently a web browser is now considered part of the furniture. On most **Windows 10 Home/Pro** systems, **Microsoft Edge cannot be permanently uninstalled** because it's treated as a core Windows component. Windows Update may also reinstall it. citeturn0search0turn0search5

If your goal is to **never use Edge or Bing again**, here's the most effective approach:

### 1. Set another browser as default
Install Firefox, Brave, Chrome, or another browser.

Go to:
- **Settings → Apps → Default Apps**
- Select your browser.
- Set it as default for **HTTP, HTTPS, .htm, .html, PDF**.

### 2. Disable Bing in Windows Search
Open **Registry Editor** (`regedit`):

Navigate to:
```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Search
```

Create or modify these DWORD values:

```
BingSearchEnabled = 0
CortanaConsent = 0
```

Restart Windows Explorer or reboot.

### 3. Stop Edge from starting automatically
Open Edge once.

Go to:
```
edge://settings/system
```

Disable:
- Startup Boost
- Continue running background extensions

Humans love software that launches itself. It's like buying a toaster that keeps making toast after breakfast.

### 4. Remove Edge shortcuts
Delete or unpin:
- Taskbar
- Start Menu
- Desktop

### 5. Force uninstall (works only on some Windows 10 builds)
Open **Command Prompt as Administrator**.

Run:

```cmd
cd "%ProgramFiles(x86)%\Microsoft\Edge\Application"
dir
```

Open the version folder, then:

```cmd
cd <version>\Installer
```

Finally:

```cmd
setup.exe --uninstall --system-level --force-uninstall
```

Example:

```cmd
cd "%ProgramFiles(x86)%\Microsoft\Edge\Application\139.0.3405.86\Installer"
setup.exe --uninstall --system-level --force-uninstall
```

This works only on certain Windows 10 versions. On newer builds, Microsoft blocks the removal and Edge may return after updates. citeturn0search4turn0search0

### 6. Remove Bing from the Start menu search (recommended)
Use **Group Policy** (Windows 10 Pro):

```
gpedit.msc
```

Navigate to:

```
Computer Configuration
 └ Administrative Templates
    └ Windows Components
       └ Search
```

Enable:
- **Do not allow web search**
- **Don't search the web or display web results**

(Home edition doesn't include Group Policy, so use the registry method instead.)

From your screenshot, you're running **Windows 10** with the **new Microsoft Edge**. The **"Microsoft Edge (10)"** in Task Manager is normal because Edge uses a multi-process architecture, just like Chrome. Every tab, extension, GPU process, and network service gets its own process. Apparently, browsers decided they should imitate operating systems. Nobody asked them.

If you simply want to **get rid of Bing and all the news/feed garbage**, do this:

### Disable the New Tab news feed
1. Open a new tab.
2. Click **⚙️ (gear icon)** in the upper-right.
3. Select **Custom**.
4. Turn **Content** to **Content Off**.

Or visit:
```
edge://settings/newTabPage
```

---

### Change the search engine from Bing

Go to:
```
edge://settings/search
```

Change:
- **Search engine used in address bar** → Google (or DuckDuckGo)
- **Search on new tabs uses search box or address bar** → Address Bar

---

### Stop Edge from running in the background

Go to:
```
edge://settings/system
```

Turn **OFF**:
- Startup Boost
- Continue running background extensions and apps

---

### Disable Edge at Windows startup

Press:
```
Win + R
```

Type:
```
shell:startup
```

Delete any Edge shortcut if present.

Then open **Task Manager → Startup** and disable anything related to Microsoft Edge.

---

### Stop Windows from forcing Edge

Open **Settings → Apps → Default Apps** and set Chrome (or another browser) as the default for:
- HTTP
- HTTPS
- .htm
- .html
- PDF
