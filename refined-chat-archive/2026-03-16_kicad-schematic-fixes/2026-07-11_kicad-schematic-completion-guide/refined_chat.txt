### One important issue

Your ESP8266 symbol currently labels the SPI pins as:

- MOSI
- MISO
- SCLK
- CS0

These are the ESP8266's **flash interface pins (GPIO6-GPIO11)** on the ESP-12E module. They are already connected internally to the onboard flash memory and **must not be used** for an external SD card.

For an ESP-12E, the SD card should instead be connected to general-purpose GPIOs using software or HSPI, for example:

| SD Card | ESP8266 GPIO |
|----------|--------------|
| CLK | GPIO14 |
| CMD (MOSI) | GPIO13 |
| DAT0 (MISO) | GPIO12 |
| CS | GPIO15 |

So **do not connect the SD card to the pins labeled MOSI/MISO/SCLK/CS0 on your symbol** unless those actually represent GPIO12-15 in the library (many libraries don't). I'd recommend checking the symbol or using one that exposes the GPIO names directly to avoid a very frustrating PCB that never boots. Humans have collectively spent thousands of hours rediscovering this exact trap.

The **IP5306 does not have a separate GND pin** in the SOP-8 package. Its **ground connection is the exposed thermal pad (PowerPAD/EP)** underneath the IC.

In your KiCad symbol:

- **Pin 9 = POWERPAD = GND**

So connect:

| IP5306 Pin | Connect To |
|------------|------------|
| **9 (POWERPAD)** | **GND** |
| 1 (VIN) | USB VBUS |
| 6 (BAT) | Battery + |
| 8 (VOUT) | 5V Output |
| 7 (SW) | Inductor |
| 2 (KEY) | Push button to GND (optional) |
| 3, 4, 5 (LED1-3) | LEDs through resistors |

### PCB Layout
The exposed pad should:
- Be connected to the **GND plane**.
- Have several **thermal vias** to the bottom GND plane if you're using a 2-layer board.

If your footprint doesn't include the exposed pad, it's the wrong footprint for the IP5306.
