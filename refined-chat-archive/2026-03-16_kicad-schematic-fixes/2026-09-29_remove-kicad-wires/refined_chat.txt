If you mean **remove every wire from the schematic while keeping all symbols, labels, footprints, etc.**, KiCad 10.0.4 makes this slightly annoying because there isn't a magical "delete all wires" button. Humanity survived somehow.

### Method 1: Select only wires and delete them

1. Open your schematic in **KiCad Schematic Editor**.
2. Press **`Ctrl + A`**.
   - This selects **everything**, so don't delete yet.
3. Open the **Selection Filter** panel on the right side.
4. **Uncheck everything except `Wires`**.
   - Leave **Wires ✅**
   - Symbols ❌
   - Labels ❌
   - Junctions ❌
   - Text ❌
   - Sheets ❌
   - etc.
5. Now press **`Ctrl + A`** again.
   - Because only **Wires** are enabled in the selection filter, KiCad should select only the wires.
6. Press **`Delete`**.

Your schematic symbols remain, while the wiring disappears.

### If junction dots remain

If you see little connection dots left behind:

1. In the Selection Filter, enable **Junctions**.
2. Press **`Ctrl + A`**.
3. Press **`Delete`**.

### Important

If you want to remove **wires + junctions + net labels**, but keep the actual components, do them separately using the Selection Filter.

For example:

| Selection Filter | Result |
|---|---|
| Wires only | Removes all wires |
| Junctions only | Removes junction dots |
| Labels only | Removes net labels |
| Wires + Junctions | Removes wiring and junctions |
| Symbols | **Don't select this** unless you want your components sacrificed to the schematic gods |

**Fastest clean reset:**  
`Selection Filter → Wires only → Ctrl+A → Delete`

That is the safest way to strip the wiring without accidentally deleting your components.

Yes. If you want a **name/logo/text physically made from copper**, like a copper trace, in the KiCad PCB layout, you should put the text on a **copper layer** such as **F.Cu** or **B.Cu**.

### In KiCad 10.0.4

1. Open your **`.kicad_pcb`** file in **PCB Editor**.

2. In the right-side **Appearance → Layers** panel, select:
   - **`F.Cu`** for copper on the top side.
   - **`B.Cu`** for copper on the bottom side.

3. Select the **Add Text** tool.
   - Usually the **`T`** hotkey can be used for text placement, depending on your hotkey configuration.
   - Or use **Place → Add Text** from the top menu.

4. Click where you want the name.

5. In the **Text Properties** window:
   - Enter your name, for example:
     `NIKI`
   - Set **Layer:** `F.Cu`
   - Choose the desired font/size.
   - Set the text thickness appropriately.

6. Click **OK** and place the text.

7. Press **`B`** to refill copper zones if you have copper pours.

Now the text is actually on **F.Cu**, so when the PCB is manufactured, it becomes **copper**, not silkscreen.

### ⚠️ One important distinction

If you simply put normal PCB text on `F.Cu`, KiCad treats it as **copper geometry**, but the exact manufacturability depends on how that text is represented and your PCB manufacturer's minimum feature rules.

For a **large decorative copper name**, this works nicely:

```text
        N I K I
████████████████████
     COPPER TEXT
```

If you want the letters to look like **actual traces**, with each letter constructed from thin copper tracks rather than filled text, there's another method using **graphic lines/arcs on F.Cu**. That gives you much more control over trace width and spacing, which is useful for a custom PCB logo.

**For normal copper lettering:** use **F.Cu → Add Text**.  
**For trace-style lettering:** use **F.Cu → graphic lines/arcs** or convert the text into copper geometry.
