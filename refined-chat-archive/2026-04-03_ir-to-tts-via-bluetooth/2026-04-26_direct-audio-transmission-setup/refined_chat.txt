## 🧠 Chain (optimized, minimal components)

- Mic modules (with onboard amplifier ✔)
- LM386 / PAM8403 amp boards ✔
- Random speakers ✔

---

## 🎯 Option 1: CLEANEST (Use PAM8403 amplifier)
That little green board with volume knob = your best friend.

### Wiring:
```
Mic Module OUT  ──||── PAM8403 INPUT (L or R)
                  C1

GND -------------- GND
VCC -------------- 5V (clean supply)
```

### Add ONLY:
- **C1 = 1µF to 10µF capacitor (series)** → blocks DC noise
- Optional: **100nF cap across VCC & GND** → removes supply noise

### Why this works:
- PAM8403 = **Class D → very low noise**
- Already optimized internally
- No nonsense

---

## 🎯 Option 2: LM386 (if you like suffering slightly more)
Works, but noisier.

### Wiring:
```
Mic OUT ──||── Pin 3 (LM386)
           C1

Pin 2 → GND
Pin 6 → 5V
Speaker → Pins 5 & GND
```

### Add:
- C1 = 10µF (input coupling)
- 100µF across supply (important or you get buzzing)
- Optional: 10µF between pin 1 & 8 (gain boost)

---

# 🎤 WHICH MIC TO USE (important or you’ll chase ghosts)

## Use THIS:
- The **blue mic module with LM393 + pot** → gives stable output

## Avoid:
- Raw electret mic (last image)  
  → needs biasing + amplifier → you said “no extra components”, so don’t pretend you’ll use it properly

# 🔇 NOISE REDUCTION (your real enemy)

You want “best audio quality”? Then do these like your life depends on it:

### 1. Power supply discipline
- Use **stable 5V (not USB garbage if noisy)**
- Add **100µF + 100nF** near amplifier

### 2. Grounding
- Single ground point  
- Don’t make spaghetti wiring like a beginner horror project

### 3. Keep wires short
- Long wires = antennas = noise festival

### 4. Shielding (if you're serious)
- Twist signal + GND wires together
