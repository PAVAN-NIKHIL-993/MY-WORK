### Suggestions & Next Steps

- Power the ESP32 from a clean 3.3 V rail: ≥100 µF bulk + 100 nF ceramic at the VDD pins, and a separate regulator for servos/motors — brownouts masquerade as random firmware bugs.
- Respect boot strapping pins (GPIO 0/2/12 on classic ESP32, GPIO 2/8/9 on C3): no external pulls that fight the straps, and never drive GPIO12 high at reset on 5 V-tolerant modules.
- Enable the hardware watchdog (esp_task_wdt) around your main loop and use deep-sleep with RTC retention for battery nodes.
- Pre-record voice prompts as 16/22 kHz 16-bit PCM WAVs on the SD card — offline, deterministic, and immune to network/cloud outages.
- Test speaker impedance vs amp output (PAM8403 @ 4 Ω vs 8 Ω) and add a 100–220 µF reservoir on the amp rail to kill clicks on simultaneous motor/LED switching.

urlVoicemeeter Bananahttps://vb-audio.com/Voicemeeter/banana.htm

A glorified virtual mixing desk for Windows. Humans looked at physical audio cables and thought, “What if we made them invisible and ten times more confusing?” Thus this thing was born.

Still, it’s insanely useful.

## What it actually does
entity["software","Voicemeeter Banana","VB-Audio virtual audio mixer for Windows"] lets you:

- Route audio between apps
- Mix mic + system sound
- Send different audio to different speakers/headphones
- Create virtual microphones
- Use virtual audio cables
- Reduce noise and control gain
- Record or stream audio cleanly

Perfect for:
- OBS streaming
- Soundboard setups
- TTS/token announcement systems
- Discord + game separation
- External keypad-triggered WAV playback
- Multi-speaker routing
- ESP32/Arduino audio experiments when Windows audio routing becomes a cursed swamp

## Your use case
From your earlier sound/token setup chaos, this is probably what you need:

### Basic architecture
```text
External Keypad / EventGhost / Soundplant
                ↓
        WAV files triggered
                ↓
       Voicemeeter Banana
                ↓
   Speaker / USB Audio / Bluetooth
```

This gives:
- cleaner routing
- volume control
- less Windows stupidity
- repeat/monitoring options
- separate outputs if needed

Because Windows audio management was apparently designed by raccoons fighting in a dumpster.

## Install order
1. Install:
   - Voicemeeter Banana
   - VB-CABLE (optional but useful)

2. Restart PC  
   Mandatory. Windows audio drivers cling to life like haunted spirits.

3. Open Voicemeeter Banana

## Main sections
### Hardware Input
Your mic or line input.

### Virtual Input
Audio from apps:
- browser
- Soundplant
- media player
- EventGhost triggers

### Hardware Out (A1/A2/A3)
Your actual speakers/headphones.

Set:
- `A1 = your main speaker`

Usually choose:
- WDM driver first
- MME only if broken

## For Soundplant WAV triggering
Set:
- Soundplant output → “Voicemeeter Input”
- In Voicemeeter:
  - enable A1 on that channel

Now keypad-triggered WAV files go through Voicemeeter to speakers.

## Best low-latency settings
Menu → System Settings:
- Preferred Main SampleRate:
  - `48000 Hz`
- Buffer:
  - 256 or 512

If crackling:
- increase buffer
- use WDM
- disable audio enhancements in Windows

urlVB-CABLE Virtual Audio Cablehttps://vb-audio.com/Cable/

Useful for:

# STEP 5: Set Your Speaker Output

Top-right corner:
```text
A1
```

Click it.

Choose your speaker:
```text
WDM: Speakers (...)
```

Example:
```text
WDM: USB Audio Device
```

ALWAYS choose:
```text
WDM
```

first.

Avoid:
```text
MME
```

unless nothing works.

# STEP 6: Make Voicemeeter Default Audio Device

Windows:
```text
Settings → Sound
```

Set:
```text
Output:
Voicemeeter Input (VB-Audio Voicemeeter VAIO)
```

Now ALL PC sound goes into Voicemeeter.

# STEP 7: Test Audio

Play YouTube.

In Voicemeeter:
- middle bars should move
- sound should come from speakers

If no sound:
- verify A1 selected
- verify speaker ON
- verify Windows volume not muted
- verify green bars moving

If bars move but no sound:
wrong A1 device selected.


etc.

# STEP 12: Add EventGhost (Optional but Powerful)

Open:
```text
EventGhost
```

- auto-repeat
- playlists
- next/prev logic

```text
Keyboard
Mouse
```

# STEP 13: Make Mouse Trigger Audio

In EventGhost:
```text
Add Macro
```

Press mouse button.

Event appears.

Add Action:
```text
Start Application
```

OR:
```text
Simulate Keystroke
```

Example:
```text
Mouse Button 4 → press key "1"
```

Now mouse triggers Soundplant WAV.
