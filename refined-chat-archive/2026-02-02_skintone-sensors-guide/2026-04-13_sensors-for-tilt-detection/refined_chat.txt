## 🧭 1. Accelerometer — the workhorse

image_group{"aspect_ratio":"1:1","query":["3 axis accelerometer diagram labeled","accelerometer working MEMS structure","phone accelerometer axis orientation","gravity vector accelerometer tilt"],"num_per_query":1}

**What it measures:** acceleration (including gravity)

Inside (MEMS tech), there’s a tiny mass suspended by microscopic springs. When you move or tilt:

- The mass shifts  
- That changes capacitance  
- Electronics convert it into X, Y, Z values  

### 🧠 Tilt detection logic:
Gravity is always there (~9.8 m/s²). So:

- Flat → Z ≈ 9.8, X ≈ 0, Y ≈ 0  
- Tilt → gravity splits across axes  

👉 So tilt = just **reading gravity direction**

### ⚡ Sudden motion:
- Quick spike in acceleration → detected as jerk, shake, or impact  
- Example: dropping phone → sudden free fall (near 0g)  

---

## 🔄 2. Gyroscope — the spin snitch

image_group{"aspect_ratio":"1:1","query":["MEMS gyroscope working principle coriolis effect","gyroscope axis rotation diagram","smartphone gyroscope orientation axes","angular velocity sensor diagram"],"num_per_query":1}

**What it measures:** angular velocity (rotation speed)

Uses the **Coriolis effect** inside a vibrating structure.

- If you rotate → internal vibration shifts  
- That shift = rotation rate  

### 🧠 Why needed?
Accelerometer alone gets confused during movement.

- Gyro tracks **how fast you're rotating**
- Helps with smooth orientation tracking  

---

## 🧩 3. Sensor Fusion — the brain (finally something smart)

No single sensor is reliable alone. So systems combine:

- Accelerometer (gravity + motion)
- Gyroscope (rotation)
- Sometimes magnetometer (direction)

Using filters like:
- Complementary filter  
- Kalman filter  

👉 Result: stable, accurate motion tracking

---

## 🚨 4. Detecting sudden events (like falls)

### Real logic used in devices:

#### 🪂 Free fall detection
- Acceleration drops close to 0g  
- Means: you're falling (not good)

#### 💥 Impact detection
- Sudden spike (>2g or more)  
- Means: hit the ground

#### 📐 Orientation change
- Body goes from vertical → horizontal  

👉 Combine all → **confirmed fall event**

# ⚙️ 📟 FULL CODE (MPU6050 FALL + MOVEMENT DETECTION)

```cpp
#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;

// Raw data
int16_t ax, ay, az;
int16_t gx, gy, gz;

// Calculated values
float A;              // Acc magnitude (g)
float angleChange;    // Rotation magnitude

// Thresholds (tune these)
float FREE_FALL_TH = 0.5;     // g
float IMPACT_TH = 2.5;        // g
float ROTATION_TH = 150;      // deg/sec
int   INACTIVITY_TIME = 3000; // ms

// State flags
bool patternBreak = false;
bool freeFall = false;
bool impact = false;
bool orientationChange = false;

unsigned long lastImpactTime = 0;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  
  mpu.initialize();

  if (!mpu.testConnection()) {
    Serial.println("MPU6050 not connected!");
    while (1);
  }

  Serial.println("MPU6050 Ready...");
}

void loop() {

  // Read sensor
  mpu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz);

  // Convert to g (approx)
  float ax_g = ax / 16384.0;
  float ay_g = ay / 16384.0;
  float az_g = az / 16384.0;

  // Magnitude of acceleration
  A = sqrt(ax_g * ax_g + ay_g * ay_g + az_g * az_g);

  // Gyro magnitude
  angleChange = sqrt(gx * gx + gy * gy + gz * gz) / 131.0;

  // -----------------------------
  // 1. Pattern break (simple)
  if (A > 1.2 || A < 0.8) {
    patternBreak = true;
  }

  // -----------------------------
  // 2. Free fall detection
  if (A < FREE_FALL_TH) {
    freeFall = true;
    Serial.println("Free Fall Detected");
  }

  // -----------------------------
  // 3. Impact detection
  if (A > IMPACT_TH) {
    impact = true;
    lastImpactTime = millis();
    Serial.println("Impact Detected");
  }

  // -----------------------------
  // 4. Orientation change
  if (angleChange > ROTATION_TH) {
    orientationChange = true;
    Serial.println("Rotation Detected");
  }

  // -----------------------------
  // 5. Fall detection logic
  if (patternBreak && impact && orientationChange) {
    Serial.println("FALL DETECTED!");
  }

  // -----------------------------
  // 6. Inactivity check
  if (impact && (millis() - lastImpactTime > INACTIVITY_TIME)) {
    if (A < 1.1 && A > 0.9) {
      Serial.println("Post-Fall Inactivity Confirmed");
    }

    // Reset states
    patternBreak = false;
    freeFall = false;
    impact = false;
    orientationChange = false;
  }

  // -----------------------------
  // 7. Movement classification (basic)

  // Walking
  if (A > 0.9 && A < 1.3 && angleChange < 100) {
    Serial.println("Walking");
  }

  // Running
  else if (A > 1.3 && angleChange > 100) {
    Serial.println("Running");
  }

  // Stairs (approx)
  else if (A > 1.1 && A < 1.6 && angleChange < 120) {
    Serial.println("Climbing Stairs");
  }

  delay(100);
}
```
