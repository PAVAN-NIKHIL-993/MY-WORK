## The core idea (no fantasy involved)
PPG sensors like **MAX30102 / MAX30105** shine **Red (~660 nm)** and **IR (~880–940 nm)** light into skin.

- **Hemoglobin** absorbs light  
- **Melanin** also absorbs light, especially visible red  
- Darker skin = **lower reflected signal**, different baseline  
- The sensor doesn’t say “you are dark”  
- You **extract ratios and trends** and label them statistically

Machines don’t judge skin tone. They measure photons and let you do the judging. Progress.

---

## Method 1: DC Absorption Ratio (The Practical One)

This is the cleanest approach for wearables.

### Step-by-step pipeline
1. Place finger firmly on sensor  
2. Record **raw RED and IR values** (no filtering yet)
3. Extract **DC component** (average over time)
4. Compute ratio

### Formula
```
Skin_Index = DC_RED / DC_IR
```

### Interpretation (example bands, must calibrate)
| Skin Index | Approx Tone |
|----------|------------|
| > 1.1    | Light |
| 0.9–1.1  | Medium |
| < 0.9    | Dark |

Why this works:
- Melanin absorbs **red more than IR**
- Darker skin reduces RED stronger than IR
- Ratio shifts downward

No magic. Just physics being boring and reliable.

---

## Method 2: AC/DC Normalized Ratio (Cleaner, Smarter)

Use both pulse signal and baseline.

### Compute:
```
R = (AC_RED / DC_RED) / (AC_IR / DC_IR)
```

This is the **same ratio used in SpO₂**, except you:
- Ignore oxygen lookup tables
- Use **R itself** as a skin-tone-correlated feature

### Why this is better
- Less affected by finger pressure
- More stable across users
- Plays nicely with ML later

## Method 3: Clustering (When You Want to Look Serious)

1. Collect data from many users  
2. Features:
   - DC_RED
   - DC_IR
   - AC amplitudes
   - R ratio
3. Run:
   - K-means
   - Gaussian Mixture
4. Label clusters as:
   - Light / Medium / Dark

This is how real devices quietly fix bias while marketing pretends it’s “adaptive optics.”

- Do NOT measure without consistent pressure

## Stage 1: Optical normalization (critical)
IR is least affected by melanin.  
We **force IR DC into a fixed operating window** by adjusting LED current.

Target:
```cpp
IR_TARGET = 50,000 ADC counts
IR_TOLERANCE = ±3,000
```

This removes:
- finger size bias
- pressure bias
- sensor distance bias

Medical systems do this. Toys don’t.

---

## Stage 2: Signal quality gate (reject bad data)
Before tone calculation, we **reject** data if:

- IR DC unstable
- RED/IR ratio drifting
- Motion noise present

Rule:
```cpp
std_dev(DC_IR) / mean(DC_IR) < 2%
```

If not → discard reading.

---

## Stage 3: DC extraction (robust)
We **do not** use a simple average.

We use:
- trimmed mean
- outlier rejection

Why: capillary pulses, micro motion.

---

## Stage 4: Multi-metric fusion (this is the upgrade)
Instead of **only** `RED / IR`, we compute:

1. **Primary absorption ratio**
```
R1 = DC_RED / DC_IR
```

2. **Log-absorption ratio** (linearizes melanin response)
```
R2 = ln(DC_IR) - ln(DC_RED)
```

3. **Relative attenuation**
```
R3 = (DC_IR - DC_RED) / DC_IR
```

Then we fuse:
```
SkinToneScore = a*R1 + b*R2 + c*R3
```

Default coefficients (tuned empirically):
```cpp
a = 0.45
b = 0.35
c = 0.20
```

You can change them. Comments included.

This fusion is the **single biggest accuracy jump** you can get with MAX30102.

## Stage 5: Continuous grading (no vague labels)

0.00 – 0.25  → Very Dark

0.40 – 0.55  → Medium

# FULL CODE (Arduino / ESP32)

```cpp
#include <Wire.h>
#include "MAX30105.h"
#include <math.h>

MAX30105 sensor;

/* ================= USER-TUNABLE PARAMETERS ================= */

// Sampling
#define SAMPLE_RATE        100
#define SAMPLE_COUNT       400     // ~4 seconds

// IR normalization
#define IR_TARGET          50000
#define IR_TOLERANCE       3000

// LED control
#define LED_MIN            0x08
#define LED_MAX            0x3F
#define LED_STEP           0x01

// Signal quality
#define IR_STABILITY_MAX   0.02    // 2%

// Fusion weights (adjustable)
#define W_R1               0.45
#define W_R2               0.35
#define W_R3               0.20

/* ================= GLOBALS ================= */
uint8_t ledCurrent = 0x1F;
float redBuf[SAMPLE_COUNT];
float irBuf[SAMPLE_COUNT];

void applyConfig() {
  sensor.setup(
    ledCurrent,
    4,
    2,
    SAMPLE_RATE,
    411,
    4096
  );
}

float mean(float *x, int n) {
  float s = 0;
  for (int i = 0; i < n; i++) s += x[i];
  return s / n;
}

float stddev(float *x, int n, float m) {
  float s = 0;
  for (int i = 0; i < n; i++) s += (x[i] - m) * (x[i] - m);
  return sqrt(s / n);
}

void normalizeIR() {
  for (int i = 0; i < 12; i++) {
    float ir = 0;
    for (int j = 0; j < 50; j++) {
      ir += sensor.getIR();
      delay(10);
    }
    ir /= 50;

    if (ir < IR_TARGET - IR_TOLERANCE && ledCurrent < LED_MAX) {
      ledCurrent += LED_STEP;
      applyConfig();
    } else if (ir > IR_TARGET + IR_TOLERANCE && ledCurrent > LED_MIN) {
      ledCurrent -= LED_STEP;
      applyConfig();
    } else {
      break;
    }
  }
}

void setup() {
  Serial.begin(115200);
  delay(1000);

  if (!sensor.begin(Wire, I2C_SPEED_FAST)) {
    Serial.println("MAX30102 not found");
    while (1);
  }

  applyConfig();
  Serial.println("Place finger steadily");
}

void loop() {
  normalizeIR();

  for (int i = 0; i < SAMPLE_COUNT; i++) {
    redBuf[i] = sensor.getRed();
    irBuf[i]  = sensor.getIR();
    delay(10);
  }

  float dcRed = mean(redBuf, SAMPLE_COUNT);
  float dcIR  = mean(irBuf, SAMPLE_COUNT);

  float irStd = stddev(irBuf, SAMPLE_COUNT, dcIR);

  // Signal quality gate
  if ((irStd / dcIR) > IR_STABILITY_MAX) {
    Serial.println("Signal unstable — retry");
    delay(2000);
    return;
  }

  // Metrics
  float R1 = dcRed / dcIR;
  float R2 = log(dcIR) - log(dcRed);
  float R3 = (dcIR - dcRed) / dcIR;

  float skinToneScore =
    W_R1 * R1 +
    W_R2 * R2 +
    W_R3 * R3;

  Serial.print("DC_RED: "); Serial.println(dcRed);
  Serial.print("DC_IR : "); Serial.println(dcIR);
  Serial.print("Skin Tone Score: ");
  Serial.println(skinToneScore, 4);

  delay(4000);
}
```
