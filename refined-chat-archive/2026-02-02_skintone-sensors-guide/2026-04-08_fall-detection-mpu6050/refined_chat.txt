# 🧠 Core Idea (a.k.a. don’t overcomplicate it)
A fall is basically a **sequence of events**, not just one spike:

1. **Free fall phase** → body loses support (acceleration drops)
2. **Impact phase** → sudden large acceleration spike
3. **Post-fall inactivity** → little or no movement afterward

If you only detect one of these, you’ll get false alarms every time someone sneezes aggressively.

---

# 📊 What MPU6050 Gives You
- **Accelerometer (Ax, Ay, Az)** → movement + gravity  
- **Gyroscope (Gx, Gy, Gz)** → rotation

You’ll mostly rely on **acceleration magnitude**.

---

# ⚙️ Step 1: Calculate Total Acceleration
Formula:

\[
A = \sqrt{Ax^2 + Ay^2 + Az^2}
\]

Normally:
- Standing still → ~1g (~9.8 m/s²)
- Free fall → ~0g
- Impact → >2g or even 3g+

---

# ⚡ Step 2: Detect Free Fall
When:

```
A < 0.5g   (for ~200–500 ms)
```

This means the body is not supported (slip, trip, etc.)

---

# 💥 Step 3: Detect Impact
Right after free fall:

```
A > 2g or 3g
```

This is the “oh no” moment.

---

# 🧍 Step 4: Detect No Movement
After impact:

```
A ≈ 1g but very stable (low variation)
```

If no movement for ~5–10 seconds → likely unconscious or lying still.

---

# 🧠 Step 5: Add Orientation Change (optional but smart)
Use angle:

\[
\theta = \tan^{-1}\left(\frac{Ax}{Az}\right)
\]

If body goes from vertical → horizontal suddenly → strong fall indicator.

---

# 🔥 Full ESP32 Code (Fall Detection Engine)

```cpp
#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;

// Acceleration variables
float ax, ay, az;
float A; // total acceleration

// Thresholds (tune these!)
#define FREE_FALL_THRESHOLD 0.5   // g
#define IMPACT_THRESHOLD    2.5   // g
#define INACTIVE_THRESHOLD  0.1   // variation
#define GYRO_THRESHOLD      200   // deg/sec

// Timing
unsigned long freeFallTime = 0;
unsigned long impactTime = 0;
unsigned long inactiveStart = 0;

// State machine
enum State {
  NORMAL,
  FREE_FALL,
  IMPACT,
  INACTIVE
};

State currentState = NORMAL;

// Previous values
float prevA = 1.0;

void setup() {
  Serial.begin(115200);
  Wire.begin();

  mpu.initialize();

  if (!mpu.testConnection()) {
    Serial.println("MPU6050 connection failed");
    while (1);
  }

  Serial.println("MPU6050 Ready...");
}

void loop() {
  int16_t rawAx, rawAy, rawAz;
  int16_t gx, gy, gz;

  mpu.getMotion6(&rawAx, &rawAy, &rawAz, &gx, &gy, &gz);

  // Convert to g (assuming ±2g range)
  ax = rawAx / 16384.0;
  ay = rawAy / 16384.0;
  az = rawAz / 16384.0;

  // Total acceleration
  A = sqrt(ax * ax + ay * ay + az * az);

  unsigned long now = millis();

  switch (currentState) {

    case NORMAL:
      if (A < FREE_FALL_THRESHOLD) {
        currentState = FREE_FALL;
        freeFallTime = now;
        Serial.println("FREE FALL DETECTED");
      }
      break;

    case FREE_FALL:
      if (A > IMPACT_THRESHOLD) {
        currentState = IMPACT;
        impactTime = now;
        Serial.println("IMPACT DETECTED");
      }
      else if (now - freeFallTime > 1000) {
        currentState = NORMAL;
      }
      break;

    case IMPACT:
      if (abs(A - prevA) < INACTIVE_THRESHOLD) {
        currentState = INACTIVE;
        inactiveStart = now;
      }
      break;

    case INACTIVE:
      if (now - inactiveStart > 5000) {
        Serial.println("🚨 FALL CONFIRMED 🚨");
        currentState = NORMAL;
      }
      else if (abs(A - prevA) > INACTIVE_THRESHOLD) {
        currentState = NORMAL;
      }
      break;
  }

  prevA = A;

  delay(50);
}
```

# Minimal ESP32 Code

```cpp
#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;

float ax, ay, az, A, prevA;

bool freeFall = false;
bool impact = false;

unsigned long impactTime = 0;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  mpu.initialize();
}

void loop() {
  int16_t rawAx, rawAy, rawAz;
  mpu.getAcceleration(&rawAx, &rawAy, &rawAz);

  ax = rawAx / 16384.0;
  ay = rawAy / 16384.0;
  az = rawAz / 16384.0;

  A = sqrt(ax*ax + ay*ay + az*az);

  // Free fall
  if (A < 0.5) {
    freeFall = true;
  }

  // Impact
  if (freeFall && A > 2.5) {
    impact = true;
    impactTime = millis();
  }

  // No movement check
  if (impact && abs(A - prevA) < 0.08) {
    if (millis() - impactTime > 5000) {
      Serial.println("FALL DETECTED");
      freeFall = false;
      impact = false;
    }
  }

  prevA = A;
  delay(50);
}
```
