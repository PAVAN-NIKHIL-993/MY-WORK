## Connections
- One side of **NTC** → **3.3V**
- Other side of **NTC** → **A0**
- One side of **68k resistor** → **A0**
- Other side of **68k resistor** → **GND**

That midpoint becomes the temperature-dependent voltage.

---

## Why this works

The NTC resistance changes with temperature:

- Temperature ↑ → NTC resistance ↓
- Temperature ↓ → NTC resistance ↑

So the voltage at A0 changes accordingly.

The ESP8266 ADC reads that voltage.

---

## Important ESP8266 Warning
Different ESP8266 boards have different ADC limits because apparently standardization offended someone deeply.

### Raw ESP8266 chip
ADC range:
```text
0V to 1.0V
```

### NodeMCU / Wemos boards
Usually already contain internal divider:
```text
0V to 3.3V
```

So:

- If using **NodeMCU/Wemos** → direct connection is fine.
- If using bare ESP8266 chip → you MUST add another divider to keep A0 below 1V.

---

## Expected Voltage

At roughly room temperature:

- NTC ≈ 65k
- Divider with 68k gives around:

# Correct Code

```cpp
#include <math.h>

#define THERMISTOR_PIN A0

// Fixed resistor value
#define SERIES_RESISTOR 68000.0

// Thermistor nominal resistance
#define NOMINAL_RESISTANCE 65000.0

// Temperature for nominal resistance
#define NOMINAL_TEMPERATURE 25.0

// Beta coefficient
#define BETA_COEFFICIENT 3950.0

// ADC settings for ESP8266
#define ADC_MAX 1023.0
#define VCC 3.3

// Number of samples
#define SAMPLES 20

void setup() {
  Serial.begin(115200);
  Serial.println();
  Serial.println("NTC Temperature Monitor Started");
}

void loop() {

  float adcAverage = 0;

  // Take multiple readings
  for (int i = 0; i < SAMPLES; i++) {
    adcAverage += analogRead(THERMISTOR_PIN);
    delay(5);
  }

  adcAverage /= SAMPLES;

  // Convert ADC to voltage
  float voltage = (adcAverage / ADC_MAX) * VCC;

  // Safety check
  if (adcAverage <= 1 || adcAverage >= 1022) {
    Serial.println("Sensor wiring error!");
    delay(1000);
    return;
  }

  // Calculate thermistor resistance
  float resistance = SERIES_RESISTOR * ((VCC / voltage) - 1.0);

  // Steinhart-Hart Equation
  float steinhart;

  steinhart = resistance / NOMINAL_RESISTANCE;
  steinhart = log(steinhart);
  steinhart /= BETA_COEFFICIENT;
  steinhart += 1.0 / (NOMINAL_TEMPERATURE + 273.15);
  steinhart = 1.0 / steinhart;

  // Convert Kelvin to Celsius
  float tempC = steinhart - 273.15;

  // Celsius to Fahrenheit
  float tempF = (tempC * 9.0 / 5.0) + 32.0;

  // Output
  Serial.print("Temperature: ");
  Serial.print(tempC, 2);
  Serial.print(" °C  |  ");

  Serial.print(tempF, 2);
  Serial.println(" °F");

  delay(2000);
}
```

```cpp
#include <math.h>

#define PIN A0

// Fixed resistor value
#define SERIES_RESISTOR 68000.0

// ESP8266 ADC settings
#define VCC 3.3
#define ADC_MAX 1023.0

// NTC values
#define NOMINAL_RESISTANCE 65000.0
#define NOMINAL_TEMPERATURE 25.0
#define BETA 3950.0

// Reading samples
#define SAMPLES 30

// Calibration
#define OFFSET 0.0
#define SCALE 1.0

void setup() {
  Serial.begin(115200);

  Serial.println();
  Serial.println("Temperature Monitoring Started");
}

void loop() {

  float adcSum = 0;

  // Take multiple readings
  for (int i = 0; i < SAMPLES; i++) {
    adcSum += analogRead(PIN);
    delay(3);
  }

  // Average ADC
  float adc = adcSum / SAMPLES;

  // Convert to voltage
  float voltage = adc * (VCC / ADC_MAX);

  // Wiring check
  if (voltage <= 0.05 || voltage >= 3.25) {
    Serial.println("Check wiring!");
    delay(1000);
    return;
  }

  // Resistance calculation
  float resistance =
      SERIES_RESISTOR * (voltage / (VCC - voltage));

  // Steinhart-Hart calculation
  float steinhart;

  steinhart = resistance / NOMINAL_RESISTANCE;
  steinhart = log(steinhart);
  steinhart /= BETA;

  // Correct Kelvin conversion
  steinhart += 1.0 / (NOMINAL_TEMPERATURE + 273.15);

  steinhart = 1.0 / steinhart;

  // Kelvin to Celsius
  float tempC = steinhart - 273.15;

  // Apply calibration
  tempC = (tempC * SCALE) + OFFSET;

  // Safety clamp
  if (tempC < 0)
    tempC = 0;

  // Celsius to Fahrenheit
  float tempF = (tempC * 9.0 / 5.0) + 32.0;

  // Serial Output
  Serial.print("Temperature: ");

  Serial.print(tempC, 2);
  Serial.print(" °C  |  ");

  Serial.print(tempF, 2);
  Serial.println(" °F");

  delay(3000);
}
```

```cpp id="jdrs71"
float medianFilter(float *arr, int size) {

  float temp[size];

  for (int i = 0; i < size; i++)
    temp[i] = arr[i];

  // Bubble sort
  for (int i = 0; i < size - 1; i++) {
    for (int j = 0; j < size - i - 1; j++) {

      if (temp[j] > temp[j + 1]) {

        float t = temp[j];
        temp[j] = temp[j + 1];
        temp[j + 1] = t;
      }
    }
  }

  return temp[size / 2];
}
```

# VERY IMPORTANT RULE IN C++

Variables/constants must be declared:
- BEFORE use
- in correct scope

This works:

```cpp id="dwb58k"
const int THERM_PIN = A0;

void loop() {
  analogRead(THERM_PIN);
}
```

This fails:

```cpp id="sy61uk"
void loop() {
  analogRead(THERM_PIN);
}

const int THERM_PIN = A0;
```

Because compiler hasn’t seen it yet.

Human languages tolerate ambiguity. C++ reacts like a Victorian schoolmaster with anger issues.
