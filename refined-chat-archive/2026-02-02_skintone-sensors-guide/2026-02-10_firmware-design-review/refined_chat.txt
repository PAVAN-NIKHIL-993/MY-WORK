## 1. Boot ROM + Image Manager  
**Verdict: Correct, boring, essential.**  
This is the “we don’t brick devices in the field” layer.

**What works**
- A/B images + rollback means you respect reality.
- CRC/SHA + boot-loop detection is non-negotiable for unattended devices.
- Reset reason capture feeds directly into your fault taxonomy. Good lineage.

**Hard truth**
- On ESP32-C3, SHA validation costs time and flash reads. Fine for wellness devices, but measure boot latency anyway.
- Boot-loop thresholds must be conservative. Aggressive rollback can oscillate if a sensor intermittently fails.

**Suggestion**
- Store *boot failure cause* alongside rollback counter. Rolling back blindly is amateur hour.

---

## 2. System Init (One-Shot)  
**Verdict: This is where real engineers reveal themselves.**

**Gold stars**
- I²C bus recovery before touching the sensor. Thank you for not trusting hardware.
- MAX30105 PART ID check early. No ghost peripherals.
- FIFO flush + watermark config before enabling tasks. Clean sequencing.
- Config version migration. You plan for time, not demos.

**Watch out**
- SCL toggle recovery must be bounded. Don’t soft-lock init if SDA is held forever.
- Safe LED defaults must be **below thermal steady-state**, not “works on my finger.”

**Suggestion**
- Log *init phase failure codes*. “INIT_FAIL_STAGE_3” saves hours later.

---

## 3. FreeRTOS Kernel  
**Verdict: Sensible paranoia.**

- TWDT + Interrupt WDT both enabled? Good. ESP32-C3 can hang creatively.
- Stack high-water enforcement per task is correct for this many moving parts.
- Heap fragmentation tracking is underrated. You didn’t underrate it.

**One warning**
- Watchdog feeding only in Acquisition is risky. If downstream tasks deadlock, you’ll keep feeding the dog while the house burns.

**Fix**
- Feed TWDT from a **heartbeat aggregator**, not a single task.

---

## 4. Hardware Timer → Acquisition  
**Verdict: This is the spine of the system.**

**Strong choices**
- Hardware timer at 100 Hz instead of vTaskDelay drift.
- esp_timer only for timestamps. Single time authority = sanity.
- FIFO burst reads reduce I²C overhead and jitter.

**Subtle risk**
- FIFO desync detection must tolerate *partial frames*, not just alignment loss.
- INT pin latency under Wi-Fi/BLE coexistence can spike.

**Suggestion**
- Track FIFO depth delta per interrupt. Detect silent overflows early.

---

## 5. Queues: Raw → Filtered  
**Verdict: Clean data contracts.**

Your structs are explicit:
- `{ts, IR, RED, frame_status}`
- `{ts, filtered_signal, quality}`

This prevents the classic “somebody reused IR as RED” bug.

**One thing**
- Queue depth monitoring should be **rate-of-change**, not absolute depth.

---

## 6. Signal Processing Task  
**Verdict: This is where most hobby code dies. Yours doesn’t.**

**Good**
- Separate DC tracking from AC processing.
- Ambient rejection before band-limiting.
- Saturation detection. Finally.

**Be careful**
- HP + LP filter order matters. DC removal must happen *before* HP.
- Resampling jitter compensation must not invent samples. Interpolate conservatively.

**Suggestion**
- Output a **filter confidence** bit alongside signal quality.

---

## 7. Beat Detection & BPM  
**Verdict: You respected physiology. That’s rare.**

**Solid**
- Refractory enforcement prevents double-counting.
- RR interval validation stops nonsense BPM spikes.
- EMA + rolling average is a good dual-view.

**Edge case**
- Bradycardia zones need wider refractory windows.
- Tachycardia detection must widen acceptance, not clamp BPM.

**Suggestion**

```cpp
/********************************************************************
 * ESP32-C3 MINI – Industrial Heart Rate Monitor Firmware
 * Sensor  : MAX30105
 * Transport: Wi-Fi (UDP dump)
 * Core    : FreeRTOS (single-core RISC-V)
 * Use     : Wellness / R&D (NON MEDICAL)
 ********************************************************************/

#include <Arduino.h>
#include <Wire.h>
#include <WiFi.h>
#include <WiFiUdp.h>
#include <esp_timer.h>
#include <esp_task_wdt.h>
#include "MAX30105.h"

/* ============================ BUILD CONFIG ============================ */
#define FW_VERSION          "1.0.0"
#define SAMPLE_RATE_HZ      100
#define TIMER_PERIOD_US     10000
#define I2C_FREQ_HZ         400000
#define WIFI_SEND_HZ        10

/* ============================ WIFI CONFIG ============================ */
#define WIFI_SSID           "YOUR_WIFI"
#define WIFI_PASS           "YOUR_PASS"
#define UDP_HOST            "192.168.1.100"
#define UDP_PORT            5005

/* ============================ WATCHDOG =============================== */
#define WDT_TIMEOUT_SEC     5

/* ============================ SENSOR ================================ */
#define IR_TARGET_DC        50000
#define LED_CURRENT_MIN     4
#define LED_CURRENT_MAX     50

/* ============================ OBJECTS ================================ */
MAX30105 sensor;
WiFiUDP udp;

/* ============================ RTOS ================================ */
QueueHandle_t q_raw;
QueueHandle_t q_filtered;
SemaphoreHandle_t sem_sample;

/* ============================ DATA STRUCTS =========================== */
typedef struct {
  uint64_t ts;
  uint32_t ir;
  uint32_t red;
  uint8_t  status;
} raw_sample_t;

typedef struct {
  uint64_t ts;
  float    ac;
  uint8_t  quality;
} filtered_sample_t;

/* ============================ SHARED STATE =========================== */
SemaphoreHandle_t mtx_shared;

volatile float current_bpm = 0.0f;
volatile uint8_t sqi = 0;
volatile bool contact = false;

/* ============================ TIMER ISR ============================== */
void IRAM_ATTR sample_timer_cb(void* arg) {
  BaseType_t hp = pdFALSE;
  xSemaphoreGiveFromISR(sem_sample, &hp);
  if (hp) portYIELD_FROM_ISR();
}

/* ============================ WIFI ================================== */
void wifi_init() {
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(200);
  udp.begin(UDP_PORT);
}

/* ============================ SENSOR INIT ============================ */
bool sensor_init() {
  Wire.begin();
  Wire.setClock(I2C_FREQ_HZ);

  if (!sensor.begin(Wire, I2C_SPEED_FAST)) return false;
  if (sensor.getPartID() != 0x15) return false;

  sensor.setup(
    LED_CURRENT_MAX,  // LED brightness
    4,                // sample avg
    2,                // mode RED+IR
    SAMPLE_RATE_HZ,
    411,              // pulse width
    16384             // adc range
  );

  sensor.clearFIFO();
  return true;
}

/* ============================ TASK: ACQUISITION ====================== */
void task_acquire(void* arg) {
  esp_task_wdt_add(NULL);

  raw_sample_t s;
  while (true) {
    xSemaphoreTake(sem_sample, portMAX_DELAY);

    if (sensor.available()) {
      s.ts = esp_timer_get_time();
      s.ir = sensor.getIR();
      s.red = sensor.getRed();
      s.status = 0;
      sensor.nextSample();
      xQueueSend(q_raw, &s, 0);
    }

    esp_task_wdt_reset();
  }
}

/* ============================ TASK: SIGNAL PROCESS =================== */
void task_filter(void* arg) {
  raw_sample_t in;
  filtered_sample_t out;
  static float dc = 0;

  while (true) {
    if (xQueueReceive(q_raw, &in, portMAX_DELAY)) {
      dc = dc * 0.99f + in.ir * 0.01f;
      out.ac = in.ir - dc;
      out.ts = in.ts;
      out.quality = (dc > 20000) ? 100 : 0;
      xQueueSend(q_filtered, &out, 0);
    }
  }
}

/* ============================ TASK: BPM ============================== */
void task_bpm(void* arg) {
  filtered_sample_t s;
  static uint64_t last_peak = 0;

  while (true) {
    if (xQueueReceive(q_filtered, &s, portMAX_DELAY)) {
      if (s.ac > 2000 && s.quality) {
        uint64_t now = s.ts;
        if (last_peak != 0) {
          float bpm = 60e6f / (now - last_peak);
          if (bpm > 40 && bpm < 200) {
            xSemaphoreTake(mtx_shared, portMAX_DELAY);
            current_bpm = 0.8f * current_bpm + 0.2f * bpm;
            sqi = 80;
            contact = true;
            xSemaphoreGive(mtx_shared);
          }
        }
        last_peak = now;
      }
    }
  }
}

/* ============================ TASK: WIFI DUMP ======================== */
void task_wifi(void* arg) {
  TickType_t last = xTaskGetTickCount();

  while (true) {
    vTaskDelayUntil(&last, pdMS_TO_TICKS(1000 / WIFI_SEND_HZ));

    xSemaphoreTake(mtx_shared, portMAX_DELAY);
    float bpm = current_bpm;
    uint8_t q = sqi;
    bool c = contact;
    xSemaphoreGive(mtx_shared);

    char buf[128];
    snprintf(buf, sizeof(buf),
      "{\"bpm\":%.1f,\"sqi\":%d,\"contact\":%d}",
      bpm, q, c
    );

    udp.beginPacket(UDP_HOST, UDP_PORT);
    udp.write((uint8_t*)buf, strlen(buf));
    udp.endPacket();
  }
}

/* ============================ SETUP ================================= */
void setup() {
  Serial.begin(115200);

  esp_task_wdt_init(WDT_TIMEOUT_SEC, true);

  sem_sample = xSemaphoreCreateBinary();
  q_raw = xQueueCreate(32, sizeof(raw_sample_t));
  q_filtered = xQueueCreate(32, sizeof(filtered_sample_t));
  mtx_shared = xSemaphoreCreateMutex();

  wifi_init();
  if (!sensor_init()) while (1);

  const esp_timer_create_args_t t = {
    .callback = sample_timer_cb,
    .dispatch_method = ESP_TIMER_ISR
  };

  esp_timer_handle_t timer;
  esp_timer_create(&t, &timer);
  esp_timer_start_periodic(timer, TIMER_PERIOD_US);

  xTaskCreatePinnedToCore(task_acquire, "acq", 4096, NULL, 6, NULL, 0);
  xTaskCreatePinnedToCore(task_filter, "filter", 4096, NULL, 5, NULL, 0);
  xTaskCreatePinnedToCore(task_bpm, "bpm", 4096, NULL, 4, NULL, 0);
  xTaskCreatePinnedToCore(task_wifi, "wifi", 4096, NULL, 2, NULL, 0);
}

/* ============================ LOOP ================================== */
void loop() {
  vTaskDelay(portMAX_DELAY);
}
```
