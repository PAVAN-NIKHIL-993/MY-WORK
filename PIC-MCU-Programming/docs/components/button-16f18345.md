# Component: button_16f18345.c

- **File:** [`02-basics/button_16f18345.c`](../../02-basics/button_16f18345.c) (64 lines) · **Module:** [firmware-basics](../modules/firmware-basics.md)
- **Purpose:** same press-toggle behavior, modern way: internal weak pull-up (no resistor), LAT writes.
- **Interface:** button RA2→GND only (WPU holds idle HIGH); LED RC5.
- **Config:** 5-line minimal + 8 MHz internal (as [18345 blink](blink-16f18345.md)); `WPUA2=1`, `nWPUEN=0` (0 = global pull-ups ON — read twice).
- **Functions:** `button_pressed()` (identical algorithm to [877A](button-16f877a.md), reads `PORTA.RA2`); `main` toggles `LATC5`.
- **Internals:** RA2 is analog-capable → `ANSELA=0` required or reads stick at 0.
- **State/errors/perf:** as 877A button. **Failure modes:** + always-pressed read if WPU/global bit misconfigured; dead if ANSEL set.
- **Debug:** check `WPUA2`/`nWPUEN` in SFR view; meter RA2 idle HIGH.
- **Extension:** IOC (interrupt-on-change) version as a stretch exercise. **Risks:** LOW; frozen (D5).
