# Component: blink_16f18345.c

- **File:** [`02-basics/blink_16f18345.c`](../../02-basics/blink_16f18345.c) (48 lines) · **Module:** [firmware-basics](../modules/firmware-basics.md)
- **Purpose:** same 1 Hz blink on the modern chip — teaches internal oscillator, ANSEL, and write-via-LAT.
- **Interface:** pin RC5 → 330 Ω → LED → GND. No crystal needed.
- **Config:** 5-line minimal `#pragma` (`FEXTOSC=OFF`, `RSTOSC=HFINTOSC`, `MCLRE=ON`, `WDTE=OFF`, `LVP=OFF`); `OSCFRQ.HFFRQ=0b100` (8 MHz) + `HFIOFR` wait; `_XTAL_FREQ 8000000`.
- **Functions:** `main(void)` — clock → `ANSELA/ANSELC=0` → `TRISC5=0` → toggle `LATC5` with 500 ms delays.
- **Internals:** boots at 1 MHz HFINTOSC, switches to 8 MHz in code; LAT writes avoid read-modify-write glitches.
- **State:** none. **Errors:** none in software; `OSCFRQ`/`_XTAL_FREQ` mismatch ⇒ wrong rate.
- **Perf/Security:** as [877A blink](blink-16f877a.md). **Failure modes:** + LED dark if ANSEL left analog (the classic modern-chip trap).
- **Debug:** verify `OSCFRQ` in Simulator SFR view; check `HFIOFR` sets.
- **Extension:** try 16 MHz (`HFFRQ=0b110`) + matching `_XTAL_FREQ`. **Risks:** LOW; frozen (D5).
